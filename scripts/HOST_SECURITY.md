# Руководство по безопасности хоста VPS (SEC-006)

Инструкция по настройке периметра сервера Linux (Ubuntu/Debian) для защиты от атак, сканирования портов и брутфорса.

---

## 🛡 Принцип защиты: Zero-Lockout

Перед отключением паролей скрипт обязательно проверяет наличие загруженных SSH-ключей в `~/.ssh/authorized_keys`. Если ключи отсутствуют, скрипт автоматически прерывает работу с предупреждением, чтобы не заблокировать администратора.

---

## 📋 Порядок применения на сервере

### Шаг 1. Проверка SSH-ключа со своего компьютера
Убедитесь, что вы можете подключаться к серверу по SSH-ключу (без ввода пароля учетной записи):
```bash
ssh -i ~/.ssh/id_ed25519 root@<IP_СЕРВЕРА>
```
Если ключ еще не скопирован:
```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@<IP_СЕРВЕРА>
```

### Шаг 2. Запуск скрипта бастионирования на VPS
Подключитесь к VPS, перейдите в папку проекта и выполните:
```bash
sudo bash scripts/harden-host.sh
```

---

## 🔍 Что делает скрипт:

1. **Контроль входа**:
   - Проверяет наличие публичных ключей в `authorized_keys`.
2. **Фаервол UFW**:
   - Запрещает все входящие соединения по умолчанию (`default deny incoming`).
   - Разрешает исходящие соединения (`default allow outgoing`).
   - Открывает только:
     - Порт `22/tcp` (SSH для администрирования).
     - Порт `80/tcp` (HTTP редирект на HTTPS в Caddy).
     - Порт `443/tcp` (HTTPS для сайта и API).
   - Все остальные порты (включая базы данных Postgres 5432 и Redis 6379) закрыты от внешнего интернета.
3. **Защита Fail2ban**:
   - Устанавливает и активирует `fail2ban`.
   - Защищает SSH: при 3 неверных попытках IP-адрес атакующего блокируется на 24 часа.
4. **Усиление SSH Daemon**:
   - `PasswordAuthentication no` — вход по паролям запрещен (защита от ботнетов).
   - `PubkeyAuthentication yes` — вход строго по криптографическим ключам.
   - `PermitEmptyPasswords no` — запрет пустых паролей.
   - `MaxAuthTries 4` — ограничение попыток аутентификации в сессии.
   - Проверяет конфигурацию командой `sshd -t` перед мягкой перезагрузкой сервиса (без разрыва текущей сессии).

---

## ⚙️ Команды оперативной проверки

### Статус фаервола:
```bash
sudo ufw status verbose
```
*Ожидаемый результат: `Status: active`, открыты только 22, 80, 443.*

### Статус Fail2ban и список заблокированных ботов:
```bash
sudo fail2ban-client status sshd
```

### Разблокировать IP (если случайно заблокировали свой адрес):
```bash
sudo fail2ban-client set sshd unbanip <ВАШ_IP>
```
